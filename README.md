# Temple Trail — Static Trip Planner

Files:
- index.html — complete itinerary
- app.css — temple-themed responsive design
- app.js — petrol/toll/local-km calculator

Open `index.html` directly in a browser. No server or build step is required.

Notes:
- Google Maps buttons open live route directions.
- Route distances/times/tolls in the page are planning estimates, not live navigation data.
- The calculator defaults to 14 km/l and ₹116/L.
- The planned car distance begins at Naidupeta by default because Gowtham starts there on Sep 30; no Hyderabad → Naidupeta driving leg is included.
- Update petrol, mileage, toll budget and local kilometres before the trip.
